# Daylist - Task Manager

This is a simple task manager website I made using HTML, CSS and JavaScript. I made it to add my daily tasks and keep track of what I have completed.

## Features

- Add new tasks
- Edit and delete tasks
- Mark tasks as completed
- View all, pending and completed tasks
- See task counts and daily progress
- Clear all completed tasks
- Tasks stay saved in the browser using local storage
- Responsive design for mobile and desktop

## Technologies Used

- HTML
- CSS
- JavaScript
